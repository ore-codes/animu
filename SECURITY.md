# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead: go to the repository's Security tab and choose "Report a vulnerability".

Include what you found, how to reproduce it and the impact you see. You can expect a first reply within a week.

## Scope

The live site is [animu.net](https://animu.net). Reports about this repository's code and the live site are welcome. Please do not run load tests or automated scans against animu.net, and do not try to read other people's data. Bookmarks live only in each customer's browser.

## Secrets

Never commit `.env`, API keys or database URLs. If you see a secret in the repository or its history, report it privately as above.
